EXHAUSTIVE SYLLABUS

Oracle SQL 12C Complete Curriculum

A step-by-step modular journey from database fundamentals to high-performance enterprise query optimization.

1. Introduction to Oracle Database

Foundation
  • Features of Oracle Database 12c & enterprise architecture
  • Basic design, theoretical, and physical aspects of relational databases (RDBMS)
  • Categorizing SQL statements: DQL, DML, DDL, DCL, and TCL
  • Exploring sample business data schemas & table relationships
  • Logging on via SQL Developer environment & executing script files
  • Saving queries, organizing worksheets, and exporting query outputs

2. Retrieve Data Using SQL SELECT

₹5,000
  • Capabilities of SQL SELECT statements (Projection & Selection)
  • Generating reports from basic SELECT queries
  • Selecting all columns vs selecting specific column subsets
  • Column aliases, custom headings, and column heading defaults
  • Arithmetic operators and operator precedence in expressions
  • DESCRIBE command to inspect table structures, nullability, and data types

3. Learn to Restrict & Sort Data

₹5,000
  • Writing queries with WHERE clauses to limit retrieved rows
  • Comparison operators (=, <>, !=, >, <, >=, <=, BETWEEN, IN, LIKE, IS NULL)
  • Logical operators (AND, OR, NOT) & rules of precedence
  • Using character string literals and case-sensitivity handling in filters
  • ORDER BY clause: Ascending (ASC) and Descending (DESC) sorting
  • Sorting by column alias, multiple columns, and positional expressions

4. Single-Row Functions to Customize Output

₹5,000
  • Differences between single-row functions and multiple-row group functions
  • Character functions: UPPER, LOWER, INITCAP, CONCAT, SUBSTR, LENGTH, INSTR, LPAD, RPAD, TRIM, REPLACE
  • Numeric manipulation with ROUND, TRUNC, and MOD functions
  • Date arithmetic: adding/subtracting days and calculating intervals
  • Date functions: MONTHS_BETWEEN, ADD_MONTHS, NEXT_DAY, LAST_DAY, ROUND, and TRUNC

5. Conversion Functions & Conditional Logic

₹5,000
  • Implicit vs explicit data type conversion rules
  • TO_CHAR, TO_NUMBER, and TO_DATE format model conversions
  • Nesting multiple functions for multi-step data transformations
  • Handling NULL values with NVL, NVL2, NULLIF, and COALESCE functions
  • Conditional expressions: CASE statements and Oracle DECODE function

6. Aggregate Data Using Group Functions

₹5,000
  • Aggregation functions: COUNT, SUM, AVG, MIN, and MAX
  • Dividing table datasets into groups using the GROUP BY clause
  • Grouping by multiple columns & aggregating subsets
  • Filtering aggregated groups using the HAVING clause
  • Key differences and rules: WHERE vs HAVING clauses

7. Display Data From Multiple Tables (Joins)

₹5,000
  • Cartesian product / Cross Joins and why they occur
  • Inner Joins (Equijoins & Non-Equijoins) using ON and USING clauses
  • Self Joins for hierarchical data (Employees & Managers)
  • Left Outer Join, Right Outer Join, and Full Outer Join syntax
  • Natural Joins and multi-table join chains

8. Use Subqueries to Solve Complex Queries

₹5,000
  • Understanding business problems that require subqueries
  • Single-row subqueries using standard relational operators
  • Multiple-row subqueries using IN, ANY, and ALL operators
  • Subqueries in WHERE, HAVING, and FROM clauses (Inline Views)
  • Correlated subqueries and EXISTS / NOT EXISTS operators

9. The SET Operators

₹5,000
  • UNION operator: combining queries and removing duplicates
  • UNION ALL operator: combining queries with duplicate retention
  • INTERSECT operator: retrieving common rows between datasets
  • MINUS operator: finding unique rows in primary dataset
  • Matching column counts, compatible datatypes, and controlling sort orders

10. Data Manipulation Statements (DML)

₹5,000
  • INSERT statement: inserting single rows and bulk rows
  • UPDATE statement: modifying existing table records
  • DELETE statement: removing specific records based on conditions
  • Transaction management: COMMIT, ROLLBACK, and SAVEPOINT
  • Read consistency, locking mechanisms, and isolation levels

11. DDL Statements to Create & Manage Tables

₹5,000
  • Categorizing database schema objects (Tables, Views, Indexes, Sequences)
  • Data types: VARCHAR2, CHAR, NUMBER, DATE, TIMESTAMP, CLOB, BLOB
  • CREATE TABLE statement and CREATE TABLE AS SELECT (CTAS)
  • Defining constraints: PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK
  • Column-level vs table-level constraint declarations

12. Schema Objects: Views, Sequences & Indexes

₹5,000
  • Creating simple and complex Views for security and reporting
  • Retrieving data from Views and DML operations on Views
  • Creating, altering, and utilizing SEQUENCES for primary keys
  • Creating and maintaining B-Tree Indexes for performance tuning
  • Creating private and public SYNONYMS for schema masking

13. Control User Access & Database Security

₹5,000
  • Differentiating system privileges from object privileges
  • Creating database users and granting login/system privileges
  • Creating and granting privileges to ROLES for group administration
  • Changing user passwords and enforcing profile constraints
  • Granting and revoking object privileges with WITH GRANT OPTION

14. Schema Object Management & Flashback

₹5,000
  • ALTER TABLE: Add, Modify, Rename, and Drop columns
  • Enabling, disabling, cascading, and deferring constraints
  • Creating Function-Based Indexes for optimized lookups
  • Performing Flashback Table and Flashback Drop operations
  • Creating external tables using ORACLE_LOADER and ORACLE_DATAPUMP

15. Data Dictionary Views Management

₹5,000
  • Understanding the Oracle Data Dictionary architecture
  • Querying USER_*, ALL_*, and DBA_* system views
  • Inspecting table metadata, column definitions, and constraint structures
  • Tracking database views, sequences, indexes, and synonym definitions
  • Adding descriptive comments to tables and columns

16. Large Data Sets & Multi-Table Inserts

₹5,000
  • Subqueries for large-scale data manipulation and transformation
  • Using Subqueries as data source and insert target
  • Enforcing integrity using the WITH CHECK OPTION keyword on DML
  • Unconditional and Conditional Multi-table INSERT statements
  • Pivoting data using Multi-table INSERT ALL / FIRST commands
