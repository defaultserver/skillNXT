₹5,000
  • Using the interactive Python REPL interpreter
  • Integrated Development Environments (IDEs): VS Code, PyCharm, Jupyter
  • Writing, saving, running, and debugging Python scripts
  • Configuring virtual environments and terminal execution

3. Python Basics, Syntax & Operators

₹5,000
  • Variables, Keywords, Statements, and Single/Multi-line comments
  • Python indentation rules and code blocks
  • Primitive data types: int, float, bool, str, None
  • Static Typing vs Dynamic Typing in Python
  • Console I/O with input() and print() formatting
  • Operators: Arithmetic, Relational, Assignment, Logical, Bitwise, Membership (in/not in), Identity (is/is not)

4. Control Flow & Iteration

₹5,000
  • Decision making: if statement, if-else, if-elif-else ladder
  • Nested conditional statements and ternary operators
  • while loops and for-in iteration over sequences
  • Nested loops and matrix traversals
  • Loop control statements: break, continue, and pass
  • Python-specific for-else and while-else constructs

5. Functions, Scope & Lambdas

₹5,000
  • Defining functions with def, parameters, and return statements
  • Positional arguments, default parameters, and keyword arguments
  • Variable-length arguments: *args and **kwargs
  • Call by object reference, local vs global scope, and global keyword
  • Recursive functions and base case design
  • Anonymous lambda functions and higher-order functions (map, filter)

₹5,000
  • Defining, organizing, and creating custom Python modules
  • Importing modules: import, from ... import, as alias
  • Inspecting module contents with dir() and __name__ == '__main__'
  • Understanding module search path (sys.path) and reload mechanisms
  • Standard library exploration: sys, os, math, datetime, random

₹5,000
  • Defining packages and creating __init__.py architecture
  • Importing sub-modules across nested directory packages
  • Installing and managing third-party libraries using pip
  • requirements.txt creation and virtual environment isolation

8. Numeric Types & Random Generation

₹5,000
  • Numeric type basics: integers, floating points, complex numbers
  • Hexadecimal (0x), Octal (0o), and Binary (0b) representations
  • Explicit typecasting: int(), float(), complex()
  • Numeric built-in functions: abs(), round(), pow(), divmod()
  • Random number generation using random and secrets modules

9. Strings & Text Processing

₹5,000
  • Defining single, double, and triple-quoted multiline strings
  • String indexing, positive/negative slicing [start:stop:step]
  • Escape sequences and raw strings r"..." for regex and paths
  • Built-in methods: split(), join(), replace(), find(), strip(), upper(), lower()
  • Modern string interpolation with f-strings and format()

10. Lists & Data Structures

₹5,000
  • List creation, heterogenous elements, and mutable indexing
  • Adding & deleting elements: append(), extend(), insert(), remove(), pop()
  • List sorting, reversing, and built-in functions (len, min, max, sum)
  • List Comprehensions with conditional filters
  • Implementing Stack (LIFO) and Queue (FIFO) data structures using lists
  • Parallel iteration with zip() and 2D matrix operations

11. Tuples & Immutability

₹5,000
  • Tuple creation, single-element tuples, and packing/unpacking
  • Accessing tuple elements and understanding immutability advantages
  • List vs Tuple memory and performance comparison
  • Tuple methods: count(), index() and tuple as dictionary keys

12. Dictionaries & Key-Value Mappings

₹5,000
  • Creating dictionaries with unique keys and hashable types
  • Accessing elements, safe retrieval with get(), and updating records
  • Deleting items with pop(), popitem(), and del
  • Dictionary methods: keys(), values(), items(), update()
  • Dictionary Comprehensions and nested dictionary JSON parsing

13. Sets & Mathematical Set Operations

₹5,000
  • Defining sets and enforcing unique element constraints
  • Set operations: Union (|), Intersection (&), Difference (-), Symmetric Difference (^)
  • Set methods: add(), update(), discard(), remove(), pop()
  • Subset and superset checks: issubset(), issuperset()
  • Set Comprehensions for rapid deduplication

14. File Handling & Serialization

₹5,000
  • File operation lifecycle: Open, Read/Write, and Close
  • File access modes: read ('r'), write ('w'), append ('a'), binary ('b')
  • Context managers: using with open(...) for automatic resource cleanup
  • Reading techniques: read(), readline(), readlines()
  • File cursor positioning with seek() and tell()
  • Binary file handling and object serialization using pickle module

15. Exception Handling & Robustness

₹5,000
  • Understanding errors vs exceptions and Python default exception handler
  • Detecting exceptions using try blocks and catching with except
  • Catching multiple exceptions and exception hierarchies
  • else block for clean code execution and finally block for guaranteed cleanup
  • Raising explicit exceptions with raise and creating custom user-defined exceptions

16. Object-Oriented Programming (OOPs)

₹5,000
  • Core OOP concepts: Classes, Objects, and Instantiation
  • Constructor __init__() and self parameter
  • Instance attributes vs Class attributes
  • Instance methods vs Class methods (@classmethod) vs Static methods (@staticmethod)
  • Encapsulation, public, protected (_), and private (__) name mangling
  • Inheritance (Single, Multiple, Multi-level) and super() method
  • Polymorphism, Method Overriding, and Operator Overloading (__str__, __len__)

17. Multi-Threading & Concurrency

₹5,000
  • Process-based multitasking vs Thread-based multitasking
  • Creating threads using function targets and subclassing threading.Thread
  • Controlling thread execution: sleep() and join() synchronization
  • Getting/setting thread names and thread logging modules
  • Thread safety: synchronization, race conditions, and Lock mechanisms
  • Inter-thread communication using queues and condition variables

18. Desktop GUI Programming with Tkinter

₹5,000
  • Introduction to Tkinter window and event loop
  • Working with widgets: Label, Button, Entry, Text, Messagebox
  • Selection widgets: Radiobutton, Checkbutton, Listbox, Combobox
  • Layout geometry managers: pack(), grid(), and place()
  • Creating Frames, Menus, Dialogs, and responsive form submissions
  • End-to-end Desktop Application Capstone Project

19. Database Programming with MySQL

₹5,000
  • Installing and setting up mysql-connector-python module
  • Establishing connection from Python to MySQL server instance
  • Creating databases and dynamic tables through Python cursors
  • Executing CRUD operations (INSERT, SELECT, UPDATE, DELETE)
  • Parameterized queries for SQL injection prevention & transaction commit()

20. Web Scraping & Data Extraction

₹5,000
  • Introduction to Web Scraping ethics, robots.txt, and HTTP status codes
  • Fetching HTML page contents using requests module
  • Parsing DOM trees using BeautifulSoup (bs4)
  • Extracting tags, attributes, CSS selectors, and table datasets
  • Structuring scraped data into clean CSV, Excel, and JSON outputs

21. Python Executable (.exe) Deployment

₹5,000
  • Understanding standalone executable compilation and distributions
  • Packaging Python scripts using PyInstaller (--onefile / --noconsole)
  • Bundling dependencies, assets, images, and data files into packages
  • Deploying standalone desktop applications for end-users
