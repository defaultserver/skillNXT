Complete Power BI Curriculum Modules

Exhaustive coverage of Power Query ETL, Power Pivot Data Modeling, DAX Calculations, Power View, and Cloud Service.

1. Power BI Complete Introduction

₹2,000
  • Power BI Ecosystem overview & modern Data Visualization principles
  • Traditional BI vs Self-Service BI (SSBI) comparison
  • Cloud-based BI vs On-Premise BI architectures
  • Power BI Product Suite: Desktop, Service, Report Server, Mobile apps
  • End-to-end flow of work in Power BI Desktop & Architecture
  • Brief history, evolution, and version updates of Microsoft BI

2. Desktop Installation & UI Overview

₹2,000
  • Installing and setting up Microsoft Power BI Desktop
  • Core building blocks: Datasets, Visualizations, Reports, Dashboards & Tiles
  • Understanding the Interface: Ribbon, Fields Pane, Visualizations Pane, Canvas
  • Working with the 3 Views: Report View, Data View, and Model View
  • Introduction to Power Query Editor for ETL (Extract, Transform, Load)

3. End-to-End Power BI Workflow

₹2,000
  • Connecting to data sources (Excel workbooks, CSV, SQL databases, Web URLs)
  • Importing data into Power BI Desktop & Power Query Editor
  • Transforming raw datasets with Power Query data cleaning
  • Modeling relationships in Power Pivot Relationship View
  • Creating dynamic DAX measures and calculated columns in Data View
  • Publishing reports to Power BI Service and sharing with teams

4. Power Query: Extract, Transform & Load

₹2,000
  • Data Transformation fundamentals & enterprise ETL pipeline benefits
  • Power Query Editor UI, Home, Transform, Add Column, and View ribbon tabs
  • Queries Pane, Data/Results Pane, Applied Steps, and Query Settings
  • Formula Bar & introduction to Advanced Editor (M Language Code)
  • Applying ETL changes and loading clean data into Power Pivot Data Model

5. Data Types & Filters in Power Query

₹2,000
  • Data types in Power Query & handling data type conversion errors
  • Auto-filtering and basic column filtering mechanisms
  • Text Filters: Starts with, Ends with, Contains, and Equals
  • Number Filters: Greater than, Less than, Between, and Top/Bottom N
  • Date Filters: Year, Month, Dynamic Relative Date, and Multi-column filters

6. Inbuilt Column Transformations

₹2,000
  • Renaming columns, Removing columns, and Removing other columns
  • Reordering, moving, and multi-level sorting of columns
  • Adding Custom Columns using M expressions and Conditional Columns
  • Splitting columns by delimiter, number of characters, and transitions
  • Merging columns, Pivot, Unpivot columns, and Transposing tables

7. Inbuilt Row Transformations

₹2,000
  • Promoting header rows / Use First Row as Headers option
  • Keep Top Rows, Keep Bottom Rows, and Keep Range of Rows
  • Keep Duplicates, Keep Errors, and error diagnostics
  • Remove Top Rows, Bottom Rows, Alternating Rows, Duplicates, and Blanks
  • Grouping rows and aggregation using Group By (Count, Sum, Avg)

8. Combine Queries: Append & Merge

₹2,000
  • Append Queries & Append Queries as New (Union Operations)
  • Batch combining multiple files of same schema from a folder using single query
  • Merge Queries (SQL Joins: Inner, Left Outer, Right Outer, Full Outer, Anti-joins)
  • Query management: Duplicate vs Reference queries
  • Enable Load, Include in Report Refresh, and Query Grouping

9. Power Pivot: Data Modeling & Relationships

₹2,000
  • Data Modeling introduction, Star Schema vs Snowflake Schema
  • Understanding relationships and Cardinality: 1-to-1, 1-to-Many, Many-to-Many
  • AutoDetecting relationships and creating/editing relationships manually
  • Active vs Inactive relationships and USERELATIONSHIP function
  • Cross-filter direction (Single vs Both) & referential integrity best practices

10. Enhancing Data Model with DAX

₹2,000
  • What is DAX (Data Analysis Expressions)? Syntax and Table/Column naming
  • Calculated Columns vs Measures (Row Context vs Filter Context)
  • Implicit Measures vs Explicit Measures
  • DAX Operators: Arithmetic (+, -, *, /), Comparison (>, <, =), Concatenation (&)
  • Logical Operators: && (AND), || (OR), ! (NOT)

11. DAX Function Categories & CALCULATE

₹2,000
  • Overview of DAX categories: Date & Time, Logical, Text, Math, Filter, Time Intelligence
  • The power of CALCULATE function: modifying filter context on the fly
  • FILTER, ALL, ALLEXCEPT, and ALLSELECTED functions
  • Time Intelligence: YTD, QTD, MTD, SAMEPERIODLASTYEAR, and DATEADD
  • Best practices for building modular measure tables

12. DAX Date, Time & Calendar Functions

₹2,000
  • Date extraction: YEAR, MONTH, DAY, WEEKDAY, and WEEKNUM
  • FORMAT function: formatting custom dates, month names, and day names
  • Current date functions: TODAY, NOW, and DATE constructor
  • Time calculations: HOUR, MINUTE, SECOND, and DATEDIFF
  • Building dedicated dynamic Date Dimension tables using CALENDAR and CALENDARAUTO

13. DAX Text, Logical & Error Handling

₹2,000
  • Text functions: LEN, CONCATENATE, LEFT, RIGHT, MID, UPPER, LOWER, TRIM, SUBSTITUTE
  • Logical branching: IF, TRUE, FALSE, NOT, OR, IN, and AND
  • Safe calculation handling: IFERROR and DIVIDE with alternative results
  • Multi-condition evaluation: SWITCH function (equivalent to nested IF / CASE)

14. DAX Math, Statistical & Iterator Functions

₹2,000
  • Rounding functions: INT, ROUND, ROUNDUP, and ROUNDDOWN
  • Math expressions: DIVIDE, EVEN, ODD, POWER, SIGN, SQRT, and FACT
  • Standard aggregation: SUM, MIN, MAX, AVERAGE, and COUNT
  • Iterator functions (X-functions): SUMX, MINX, MAXX, AVERAGEX, and COUNTX

15. Power View & Visual Canvas

₹2,000
  • Report View interface: Fields Pane, Visualizations Pane, Format Pane
  • Managing Visual Interactions: Filter, Highlight, or None
  • Configuring Default Visual Interaction behavior across charts
  • Page layouts, canvas background formatting, wallpaper, and grid alignments
  • Creating bookmark actions and custom navigation panels

16. Filters, Grouping, Binning & Sorting

₹2,000
  • Filter scope: Visual Level, Page Level, Report Level, and Drill-Through filters
  • Filter subtypes: Basic, Advanced, Top N, and Relative Date filtering
  • Creating text groups and numeric/date binning for distribution analysis
  • Sorting visuals by custom columns (Sort by Column feature)
  • Multi-level drill-down and drill-up hierarchies

17. Visualizing Trends & Advanced Charts

₹2,000
  • Line Charts, Area Charts, and Stacked Area Charts for time-series
  • Combo Charts: Line and Stacked Column Chart, Line and Clustered Column Chart
  • Ribbon Charts, Waterfall Charts for variance analysis, and Funnel Charts
  • Scatter plots, Bubble charts, Decomposition Tree, and Key Influencers visual

18. Visualizing KPIs & Executive Cards

₹2,000
  • Creating and formatting Gauge Visuals with target indicators
  • KPI Visuals with trend axis, status indicators, and goal targets
  • Single Card Visualizations, Multi-Row Cards, and new Card (Preview) features
  • Conditional formatting on visuals: background color, font color, data bars, icons

₹2,000
  • Power BI Service cloud architecture & account creation
  • Publishing reports from Desktop to Cloud Workspaces
  • My Workspace vs App Workspaces (collaborative team workspaces)
  • Managing Cloud Datasets, Reports, and Workbooks
  • Live connection to datasets and row-level security (RLS) enforcement

20. Cloud Dashboards & Work Sharing

₹2,000
  • Building executive Cloud Dashboards in Power BI Service
  • Pinning individual visuals and pinning LIVE report pages to dashboards
  • Adding dashboard tiles: Web content, Images, Text boxes, Video widgets
  • Sharing dashboards, generating QR codes, and creating Power BI Apps
  • Configuring scheduled email subscriptions and alert notifications

₹2,000
